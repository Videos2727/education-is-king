StudyGrader Lessons

Online lessons using PowerPoint slide images

Welcome

This free website lets students view lessons online. PowerPoint files are converted into slide images, so students do not receive the original PowerPoint file.

Important: This makes downloading harder, but students can still take screenshots. Do not upload the original PowerPoint file for students.

Free setup

1. Convert PowerPoint

Export your PowerPoint as PNG/JPEG images.

2. Upload to GitHub

Put slide images inside the lessons folder.

3. View lessons

Students open lessons inside this website.

Admin Lesson Setup

For the free GitHub version, you add lessons by uploading slide images into your GitHub folders and editing the lesson list in the code.

Add a new lesson

Copy one lesson object inside the JavaScript lessonData section and change the title, slide image links and question.
